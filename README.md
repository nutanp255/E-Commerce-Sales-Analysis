
# E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes the Sample Superstore dataset to evaluate sales performance, profitability, product trends, and regional performance using Python. The objective is to transform raw sales data into meaningful business insights through data analysis and visualization.

## 🎯 Objectives

- Calculate total sales, profit, and quantity sold.
- Compare sales and profit across product categories and regions.
- Identify top-performing products based on sales.
- Analyze monthly sales trends.
- Examine the relationship between discounts and profit.
- Visualize key patterns using charts.
- Generate insights to support business decision-making.

## 🛠️ Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook
- GitHub

## 📂 Dataset

This project uses the `Sample_Superstore.csv` dataset for sales analysis.

The dataset contains sales transaction details, including order dates, customer segments, product categories, regions, sales, quantities, discounts, and profits.

### Key Columns

- `Order Date` — Date when the order was placed.
- `Segment` — Customer segment.
- `Region` — Sales region.
- `Category` — Product category.
- `Sub-Category` — Product sub-category.
- `Product Name` — Name of the product.
- `Sales` — Sales amount.
- `Quantity` — Quantity sold.
- `Discount` — Discount applied to an order.
- `Profit` — Profit or loss from a sale.

## 🔄 Project Workflow

1. **Import Libraries** — Import Pandas, NumPy, Matplotlib, and Seaborn.
2. **Load Dataset** — Load `Sample_Superstore.csv` using Pandas.
3. **Data Exploration** — Examine the dataset using `head()`, `shape`, `info()`, and `describe()`.
4. **Data Quality Checks** — Identify missing values, duplicate records, and data type issues.
5. **Sales KPI Analysis** — Calculate total sales, total profit, and total quantity sold.
6. **Category-wise Analysis** — Compare sales and profit by category and sub-category.
7. **Region-wise Analysis** — Evaluate sales and profit across regions.
8. **Product Analysis** — Identify top-performing products and loss-making sub-categories.
9. **Monthly Sales Analysis** — Analyze sales trends over time.
10. **Discount and Profit Analysis** — Examine the relationship between discounts and profitability.
11. **Data Visualization** — Create charts using Matplotlib and Seaborn.
12. **Business Insights** — Summarize findings based on the analysis results.

## 📊 Key Analysis Areas

- Overall sales, profit, and quantity
- Category-wise and sub-category-wise performance
- Region-wise sales and profit
- Monthly sales trends
- Top products by sales
- Discount versus profit

## ⚠️ Limitations and Assumptions

### Limitations

- The analysis depends on the accuracy of the provided dataset.
- Historical data may not reflect future sales trends.
- External factors such as marketing and competition are not fully considered.

### Assumptions

- Dataset values are assumed to be reasonably accurate.
- Negative profit values represent losses.
- Findings are based on the available data and analysis.
